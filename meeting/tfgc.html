Abstract

摘要

With the rapid rise of Large Vision Language Models (LVLMs) for image understanding, the objective of image compression is gradually shifting from human visual perception to machine-oriented semantic understanding.

随着大型视觉语言模型（LVLM）在图像理解领域迅速兴起，图像压缩的目标正逐渐从人类视觉感知转向面向机器的语义理解。

However, conventional learned compression techniques are optimized for pixel-level fidelity and typically operate at fixed or rigid bitrate points, misaligned with the semantic consistency and flexible bitrate control.

然而，传统的学习式压缩技术以像素级保真度为优化目标，通常工作在固定或缺乏灵活性的码率点，难以满足语义一致性与灵活码率控制的要求。

This gap becomes critical in ultra-low-bitrate regimes,

这种差距在极低码率下尤为突出。

where latent representations often ignore semantic relevance and struggle to disentangle meaningful content from redundant visual details as the bitrate varies.

随着码率变化，潜在表示往往忽略语义相关性，难以将有意义的内容与冗余视觉细节区分开来。

To address these challenges, we develop a token-based flexible compression framework, Token Flow Guided Compression (TFGC), which unifies human- and machine-oriented objectives.

为应对这些挑战，我们提出了基于词元的灵活压缩框架——词元流引导压缩（TFGC），统一面向人类和机器的优化目标。

TFGC supports variable bitrate control in ultra-low bitrate regimes and enables LVLMs to directly process compressed tokens without image reconstruction.

TFGC 支持极低码率下的可变码率控制，并使 LVLM 无需重建图像即可直接处理压缩词元。

Specifically, we explore the token flow phenomenon in 1D token sequences and exploit it to design token flow propagation,

具体而言，我们研究一维词元序列中的词元流现象，并据此设计词元流传播机制。

which predicts missing tokens by propagating contextual information from unmasked tokens.

该机制传播未掩码词元的上下文信息，以预测缺失词元。

Moreover, token semantic guidance aligns compressed representations with LVLM semantic space,

此外，词元语义引导将压缩表示与 LVLM 的语义空间对齐。

while a progressive semantic alignment training strategy further bridges the gap between perceptual reconstruction and semantic reasoning.

渐进式语义对齐训练策略进一步弥合感知重建与语义推理之间的差距。

Experiments show that our framework achieves state-of-the-art LVLMs understanding at comparable bitrates while maintaining satisfactory perceptual quality.

实验表明，在相近码率下，该框架使 LVLM 的理解性能达到当前先进水平，同时保持良好的感知质量。

1. Introduction

1. 引言

Large Vision-Language Models [1, 3, 32, 38, 66] (LVLMs) have significantly advanced multi-task image understanding by integrating visual features into LLMs, redefining how visual data are consumed by both humans and machines.

大型视觉语言模型（LVLM）[1, 3, 32, 38, 66] 将视觉特征融入大语言模型（LLM），显著推动了多任务图像理解，也改变了人类与机器使用视觉数据的方式。

This shift fundamentally changes the objective of image compression, which must now preserve not only perceptual fidelity but also semantic consistency for machine reasoning [28, 58].

这一转变从根本上改变了图像压缩的目标。压缩需要保持感知保真度，同时维持机器推理所需的语义一致性 [28, 58]。

Meanwhile, real-world scenarios such as satellite transmission and edge devices demand ultra-low and variable bitrate compression under constrained bandwidth and computation [19, 25, 35, 52, 54].

与此同时，卫星传输和边缘设备等实际场景受限于带宽和算力，需要支持极低码率和可变码率的压缩技术 [19, 25, 35, 52, 54]。

Existing learned autoencoder-based image compression methods can be categorized as follows.

现有基于自编码器的学习式图像压缩方法可作如下归纳。

Typical approaches [17, 18, 20, 26, 49, 67] employ an autoencoder framework [21] that jointly optimizes, achieving superior performance over traditional codecs such as BPG [4], and VVC [6].

典型方法 [17, 18, 20, 26, 49, 67] 采用自编码器框架 [21] 进行联合优化，性能优于 BPG [4]、VVC [6] 等传统编解码器。

However, these models are usually trained for a specific bitrate by tuning the rate–distortion coefficient λ in the loss R+λD,

然而，这些模型通常通过调整损失 R+λD 中的率失真系数 λ 来针对某一特定码率训练。

requiring retraining or storing separate checkpoints for different operating points.

因此，不同工作点需要重新训练或存储独立的模型检查点。

To address this limitation, QVRF [52] introduces a quantization-regulator vector for controlling latent quantization error, while Hanyue [54] employs a lightweight multi-scale invertible transform for unified bitrate control.

为克服这一局限，QVRF [52] 引入量化调节向量以控制潜变量的量化误差，而 Hanyue [54] 采用轻量级多尺度可逆变换实现统一的码率控制。

With the rise of LVLMs, recent works [28, 39] attempt to incorporate semantic priors into compression.

随着 LVLM 兴起，近期研究 [28, 39] 尝试将语义先验引入压缩过程。

However, these methods still rely on reconstructed images, creating a modality gap between perceptual fidelity and machine understanding.

然而，这些方法仍依赖重建图像，在感知保真度与机器理解之间形成模态鸿沟。

This issue becomes more pronounced in ultra-low bitrate regimes [25, 30, 53, 59], where semantic degradation severely impacts downstream reasoning.

这一问题在极低码率下更为明显 [25, 30, 53, 59]，此时语义退化会严重影响下游推理。

This underscores the necessity of maintaining semantic integrity when operating in ultra-low-bitrate regimes.

这凸显了在极低码率下保持语义完整性的必要性。

Recent Vector-Quantized (VQ) based approaches [23, 41, 44] transmit discrete token indices but typically rely on dense 2D token grids, limiting compression flexibility.

近期基于矢量量化（VQ）的方法 [23, 41, 44] 传输离散词元索引，但通常依赖密集的二维词元网格，限制了压缩的灵活性。

In contrast, our approach employs a tokenizer-based 1D token representation that is both more compact and semantically enriched,

相比之下，我们的方法采用基于词元化器的一维词元表示。这种表示更紧凑，语义信息也更丰富。

yielding higher compression efficiency and a more informative latent stream for LVLM-based image understanding.

因此，它能提高压缩效率，并为基于 LVLM 的图像理解提供信息更丰富的潜在数据流。

To further explore the structural and semantic characteristics of these 1D tokens, we conduct token information perturbation analyses, as shown in Fig.3.

为进一步探究这些一维词元的结构和语义特性，我们开展了词元信息扰动分析，如图 3 所示。

By comparing the effects of injecting different types of perturbations, we observe a unique property of 1D tokens—token flow—which reflects their inherent ability to preserve global consistency across the sequence.

通过比较不同扰动的影响，我们观察到一维词元具有一种独特属性，即词元流。这一属性体现了词元序列维持全局一致性的内在能力。

Leveraging this insight, we propose Token Flow Guided Compression (TFGC), a unified compression framework jointly optimized for human perception and machine understanding.

基于这一发现，我们提出词元流引导压缩（TFGC），在统一框架中联合优化人类感知与机器理解。

Main contributions are summarized as follows:

主要贡献如下。

• We explore an inherent phenomenon in 1D token representations, termed “token flow”, which describes the dynamic propagation of semantic information across token sequences.

• 我们探究了一维词元表示中的一种内在现象，称为“词元流”，用以描述语义信息在词元序列中的动态传播。

Building on this insight, we develop the Token Flow Guided Compression (TFGC) framework, enabling variable-bitrate adaptation and direct LVLM consumption of the compressed bitstream.

基于这一发现，我们开发了词元流引导压缩（TFGC）框架，使其适应可变码率，并支持 LVLM 直接使用压缩码流。

• We design a Token Flow Propagation (TFP) module tailored for variable-bitrate settings.

• 我们针对可变码率场景设计了词元流传播（TFP）模块。

By modeling masked tokens as conditional Gaussian distributions and adaptively transforming a standard Gaussian prior into target conditionals, TFP achieves fine-grained bitrate modulation within a single model.

TFP 将被掩码的词元建模为条件高斯分布，并将标准高斯先验自适应地变换为目标条件分布，从而在单一模型内实现细粒度码率调节。

• We introduce a lightweight Token Semantic Guidance (TSG) module that aligns visual tokens with the semantic features expected by LVLMs.

• 我们引入轻量级的词元语义引导（TSG）模块，将视觉词元与 LVLM 所需的语义特征对齐。

By bypassing the redundant “decode-then-encode” process, TSG enables direct token-based reasoning and substantially enhances understanding performance under ultra-low bitrates.

TSG 跳过冗余的“先解码、再编码”过程，实现直接基于词元的推理，显著提升极低码率下的理解性能。

2. Related Work

2. 相关工作

Image Compression.

图像压缩。

End-to-end neural compression, particularly autoencoder-based methods [12, 42, 46], has substantially improved over classical codecs but often yields overly smooth reconstructions and missing details at ultra-low bitrates [22].

端到端神经压缩方法，尤其是基于自编码器的方法 [12, 42, 46]，相比传统编解码器取得了明显进步，但在极低码率下往往出现重建过度平滑、细节缺失的问题 [22]。

[7, 25, 35] leverage diffusion-based generation to synthesize fine details at extremely low rates.

研究 [7, 25, 35] 使用基于扩散的生成方法，在极低码率下合成细节。

However, most end-to-end models lack flexible variable-bitrate control and typically require retraining or maintaining separate models per bitrate, incurring substantial computational and storage costs.

然而，大多数端到端模型缺少灵活的可变码率控制，通常需要为不同码率重新训练或维护独立模型，导致较高的计算和存储开销。

To address variable bitrate requirements, other approaches [52, 54] leverage conditioning vectors or scale-adaptive transforms to modulate the latent features, enabling operating different bitrates without retraining separate models.

为满足可变码率需求，其他方法 [52, 54] 使用条件向量或尺度自适应变换来调制潜在特征，从而以同一模型支持不同码率。

Token Compression.

词元压缩。

Vector-quantized (VQ) token–based compression, which transmits discrete token indices rather than quantized features, has recently attracted growing attention.

基于矢量量化（VQ）的词元压缩传输离散词元索引而非量化特征，近期受到越来越多的关注。

Such approaches typically use encoders that fall into 2D autoencoders and 1D tokenizers.

这类方法通常采用两类编码器，即二维自编码器和一维词元化器。

The 2D autoencoders [13, 27, 50, 55] preserve spatial alignment by mapping image patches to latent tokens,

二维自编码器 [13, 27, 50, 55] 将图像块映射为潜在词元，以保持空间对齐。

whereas 1D tokenizers [2, 8, 47, 61] leverage Transformer-based [56] architectures to capture more compact semantic information of image.

一维词元化器 [2, 8, 47, 61] 则采用基于 Transformer [56] 的架构，以更紧凑的形式提取图像语义信息。

To further compress token sequence, existing methods either employ non-learned approaches such as clustering or folding to modify the sequence’s geometric structure [29, 31, 48, 64],

为进一步压缩词元序列，现有方法采用聚类、折叠等非学习方法改变序列的几何结构 [29, 31, 48, 64]，

or introduce learnable masking guided by external textual cues or static token registers to refine the sequence’s content [2, 40, 62].

或引入由外部文本线索或静态词元寄存器引导的可学习掩码，以优化序列内容 [2, 40, 62]。

These methods lack flexibility in token-sequence compression and recovery.

这些方法在词元序列的压缩和恢复上缺乏灵活性。

In our work, we employ a token dropout strategy to reduce sequence length and introduce a token flow propagated prediction strategy to recover the complete sequence, enabling adaptive and effective variable bitrate compression.

我们采用词元丢弃策略缩短序列，并通过词元流传播预测恢复完整序列，实现自适应且有效的可变码率压缩。

Compression for Machine.

面向机器的压缩。

Recently, compression for machine perception has gained increasing attention.

近年来，面向机器感知的压缩受到越来越多的关注。

Some approaches [33, 34, 51, 63] train compression systems with specific downstream networks to optimize performance for targeted tasks.

部分方法 [33, 34, 51, 63] 将压缩系统与特定下游网络联合训练，以优化目标任务的性能。

However, such methods are task-specific, requiring retraining for each new application.

然而，这些方法针对特定任务，每加入一种新应用都需要重新训练。

With LVLMs unifying diverse vision tasks, [28, 39] add semantic pre-editing or pre-selection to make compressed images oriented toward LVLMs.

随着 LVLM 统一多种视觉任务，研究 [28, 39] 引入语义预编辑或预选择，使压缩图像更适合 LVLM 处理。

In our work, our framework uses lightweight semantic guidance to bypass redundant decode-then-encode steps, allowing the compressed token bitstream to be directly interpreted as visual features for LLMs.

我们的框架通过轻量级语义引导跳过冗余的先解码再编码步骤，使压缩词元码流可以直接作为 LLM 的视觉特征。

3. Method

3. 方法

3.1. Overall Architecture

3.1. 整体架构

In this study, we investigate a unified variable bitrate image compression framework, Token Flow Guided Compression (TFGC), that jointly supports human visual perception and machine understanding under extremely low-bitrate constraints.

本文研究统一的可变码率图像压缩框架 TFGC，在极低码率约束下同时支持人类视觉感知和机器理解。

As shown in Fig. 2, TFGC consists of four key components: (1) a 1D tokenizer–detokenizer for visual tokenization and reconstruction, (2) a variable bitrate control module based on Token Flow Propagation (TFP),

如图 2 所示，TFGC 由四个关键部分组成：（1）用于视觉词元化与重建的一维词元化器和反词元化器，（2）基于词元流传播（TFP）的可变码率控制模块，

(3) a Token Semantic Guidance (TSG) module for semantic alignment, and (4) a large language model (LLM) for downstream understanding.

（3）用于语义对齐的词元语义引导（TSG）模块，以及（4）用于下游理解的大语言模型（LLM）。

Specifically, at the encoder side, the image is first converted into 1D token sequences by the tokenizer.

具体而言，在编码端，词元化器先将图像转换为一维词元序列。

A variable token masker removes a controllable portion of tokens based on the target bitrate, and the remaining unmasked tokens are entropy-coded into a bitstream using an arithmetic encoder.

可变词元掩码器根据目标码率去除一定比例的词元，再由算术编码器对剩余的未掩码词元进行熵编码，生成码流。

At the decoder side, the transmitted bitstream is recovered by the arithmetic decoder, followed by the TFP module, which predicts the missing tokens to reconstruct the full token sequence.

在解码端，算术解码器先解码传输的码流，随后 TFP 模块预测缺失的词元，恢复完整序列。

This reconstructed token sequence serves two parallel pathways: (i) image reconstruction through the detokenizer for human-oriented perception, and (ii) semantic adaptation through the TSG module for LLM-based understanding.

恢复后的词元序列进入两条并行路径：（i）由反词元化器重建图像，服务于人类感知；（ii）由 TSG 模块进行语义适配，服务于基于 LLM 的理解。

3.2. Token Flow Perceptual Reconstruction

3.2. 词元流感知重建

3.2.1. Token Flow

3.2.1. 词元流

The 1D token sequence removes the spatial correspondence inherent in 2D tokens, resulting in a highly compressed representation [2, 61], which is mainly manifested in its “feature representation” properties.

一维词元序列消除了二维词元固有的空间对应关系，从而形成高度压缩的表示 [2, 61]，其特点主要体现在特征表示属性上。

[5] pointed out the positional property of feature representation, which means tokens at specific positions tend to encode specific attributes such as color, pose, background, etc.

研究 [5] 指出，特征表示具有位置属性，即特定位置的词元倾向于编码颜色、姿态、背景等特定属性。

[2] highlighted the sequential property of feature representation, noting that tokens at the beginning of the sequence tend to encode global features, while tokens toward the end capture fine-grained details.

研究 [2] 强调了特征表示的顺序属性，即序列开头的词元倾向于编码全局特征，靠近末尾的词元则捕捉细节。

In this paper, we emphasize the holistic property of feature representation: the entire token sequence jointly carries the semantic and structural information of the image, making token-based variable-rate control possible.

本文强调特征表示的整体性：整条词元序列共同承载图像的语义和结构信息，因此可以基于词元实现可变码率控制。

Moreover, the Transformer-based architecture of the 1D tokenizer naturally introduces a self-attention mechanism, which transforms this holistic representation into a dynamic process of information exchange.

此外，一维词元化器的 Transformer 架构包含自注意力机制，使这种整体表示体现为动态的信息交换过程。

This mechanism compensates for the loss of explicit spatial relationships caused by flattening 2D features into a 1D sequence, allowing tokens to communicate globally and model long-range dependencies.

该机制弥补了二维特征展平为一维序列时丢失的显式空间关系，使词元能够在全局范围内交换信息并建模长距离依赖。

We refer to this as token flow, which describes how visual information is globally propagated and contextually recovered within the 1D token sequence.

我们将这一现象称为词元流，用于描述视觉信息如何在一维词元序列中全局传播，并借助上下文恢复。

We conducted token flow perturbation experiments to verify the holistic property in 1D token representations.

我们开展了词元流扰动实验，以验证一维词元表示的整体性。

As shown in Fig. 3, two perturbation types are explored: obstruction tokens that introduce foreign information relative to the original token sequence, and uninformative tokens that simply remove information without inserting new content.

如图 3 所示，我们考察两种扰动：干扰词元向原序列引入外来信息，无信息词元只移除信息，不添加新内容。

For obstruction tokens, we replace the tail tokens of the original sequence with randomly sampled tokens from the codebook.

对于干扰词元，我们用从码本中随机采样的词元替换原序列的末尾词元。

When only a few obstruction tokens are inserted, the reconstructed image maintains a stable overall style;

仅插入少量干扰词元时，重建图像的整体风格保持稳定。

however, increasing their proportion gradually disrupts the information flow, leading to severe degradation.

但随着干扰词元比例提高，信息流逐渐受到破坏，重建质量严重下降。

In contrast, for uninformative tokens, we directly remove tokens at the end or at random positions.

对于无信息词元，我们直接移除序列末尾或随机位置的词元。

We find that this usually causes less disruption than introducing the same number of obstruction tokens.

我们发现，这通常比引入相同数量的干扰词元造成的破坏更小。

This arises from the token flow in the 1D tokenizer, which allows remaining valid tokens that carry holistic features to propagate contextual information globally.

原因在于一维词元化器中的词元流允许保留的有效词元凭借其携带的整体特征，在全局范围内传播上下文信息。

However, when excessive obstruction tokens are introduced, their interference overwhelms meaningful information exchange, whereas uninformative tokens merely remove information without injecting conflicting noise.

然而，干扰词元过多时，其干扰会压过有效的信息交换，而无信息词元只移除信息，不引入冲突噪声。

3.2.2. Token Flow Propagation

3.2.2. 词元流传播

Several techniques have been developed for compressing 1D token sequences—such as pixelshuffle, token folding, clustering, and dropout

用于压缩一维词元序列的技术包括像素重排、词元折叠、聚类和丢弃。

—enabling a single model to generate representations at multiple compression levels by adjusting the number of retained tokens.

通过调整保留词元的数量，单一模型便可生成不同压缩程度的表示。

Nevertheless, these approaches mainly emphasize token reduction while neglecting the modeling of information prediction or recovery from the compressed representations.

然而，这些方法主要关注减少词元数量，对如何从压缩表示中预测或恢复信息缺乏建模。

This limitation becomes critical in variable-bitrate scenarios, where reliable recovery of the full token sequence from reduced representations is essential for maintaining content consistency across different bitrate levels.

在可变码率场景下，这一局限尤为突出，因为要让不同码率下的内容保持一致，必须能够从精简表示中可靠地恢复完整词元序列。

This inspires us to explore methods to maximize informative content transmission while minimizing the introduction of external disruptive noise.

为此，我们探索如何尽量多地传递有效信息，同时尽量少地引入外部干扰噪声。

However, existing token prediction techniques [2, 40, 62]

然而，现有词元预测方法 [2, 40, 62] 本质上是静态的。

—whether implemented as a single learnable token or as a set of learnable tokens with positional encoding to supplement the original token sequence—are inherently static, meaning that they operate independently of other tokens.

无论用单个可学习词元，还是用带位置编码的一组可学习词元补充原始序列，填补过程都独立于其他词元。

Consequently, the model is forced to learn a replacement token distribution that is applied across all contexts, which weakens the information flow capability of 1D tokens.

因此，模型只能学习一种适用于所有上下文的替换词元分布，削弱了一维词元传播信息的能力。

Let the original token sequence be x=(x1,x2,…,xN), and partition it into unmasked part xu=(x1,x2,…,xn) and masked part xm=(xn+1,xn+2,…,xN).

设原始词元序列为 x=(x1,x2,…,xN)，将其划分为未掩码部分 xu=(x1,x2,…,xn) 和被掩码部分 xm=(xn+1,xn+2,…,xN)。

Let the true joint distribution be P(x)=P(xu,xm)=P(xu)P(xm∣xu), and let F(xm) be an arbitrary context-free distribution.

设真实联合分布为 P(x)=P(xu,xm)=P(xu)P(xm∣xu)，并令 F(xm) 为任意与上下文无关的分布。

A static token filling strategy corresponds to a joint distribution Q(x)=P(xu)F(xm).

静态词元填补策略对应联合分布 Q(x)=P(xu)F(xm)。

The distance between the true distribution and the static token joint distribution can be expressed via KL divergence:

真实分布与静态词元填补所对应的联合分布之间的差异，可用 KL 散度表示。

(1)DKL(P∥Q)=Ex∼P[log⁡P(x)Q(x)]=Ex∼P[log⁡P(xu)P(xm∣xu)P(xu)F(xm)]=Ex∼P[log⁡P(xm∣xu)−log⁡F(xm)]=Exu∼P(xu)[Exm∼P(⋅∣xu)[log⁡P(xm∣xu)F(xm)]]=Exu∼P(xu)[DKL(P(xm∣xu)∥F)].

That is, the discrepancy caused by replacement equals the average KL divergence between the conditional distribution P(xm∣xu) and the replacement distribution F.

也就是说，替换所造成的差异等于条件分布 P(xm∣xu) 与替换分布 F 之间的平均 KL 散度。

As long as the unmasked part xu and the masked part xm are not independent, any F unrelated to the conditional distribution will generally make the above expression positive and significant.

只要未掩码部分 xu 与被掩码部分 xm 不独立，任何与条件分布无关的 F 通常都会使上式得到显著的正值。

This proves that replacing with context-free static tokens disrupts the original global feature structure.

这说明，使用与上下文无关的静态词元进行替换会破坏原有的全局特征结构。

To preserve the inter-token dependencies induced by token flow, we instead aim to model the conditional distribution P(xm∣xu).

为保留词元流产生的词元间依赖关系，我们改为对条件分布 P(xm∣xu) 建模。

For analytical tractability, we assume that the joint distribution P(xu,xm) follows a multivariate Gaussian form, which provides a closed-form expression for its conditional: P(xm∣xu)=N(μm∣u,Σm∣u), where

为便于分析，我们假设联合分布 P(xu,xm) 服从多元高斯分布，从而可写出条件分布的闭式表达 P(xm∣xu)=N(μm∣u,Σm∣u)，其中均值和协方差如下。

(2)μm∣u=μm+ΣmuΣuu−1(xu−μu),Σm∣u=Σmm−ΣmuΣuu−1Σum.

The conditional mean μm∣u, being an affine function of xu, supports the theoretical foundation for predicting the missing tokens xm from the unmasked tokens xu.

条件均值 μm∣u 是 xu 的仿射函数，为根据未掩码词元 xu 预测缺失词元 xm 提供了理论依据。

The conditional covariance Σm∣u is independent of xu, implying that a single scale is sufficient to characterize the uncertainty of the missing region.

条件协方差 Σm∣u 与 xu 无关，这意味着单一尺度足以刻画缺失区域的不确定性。

This property supports a parameterized conditional modeling framework that captures both prediction and uncertainty.

这一性质为同时刻画预测值与不确定性的参数化条件建模框架提供了依据。

In practice, we adopt a parameterized conditional distribution strategy: let μθ(xu) denote the network prediction that approximates the true conditional mean μm∣u

实际中，我们采用参数化的条件分布建模策略。令 μθ(xu) 表示网络对真实条件均值 μm∣u 的估计，

and let σθ(xu) denote a network output that parameterizes the conditional scale, relaxing the fixed-covariance assumption of the strict Gaussian model.

令 σθ(xu) 表示网络输出的条件尺度，从而放宽严格高斯模型的固定协方差假设。

Sampling from the learned conditional is done via reparameterization:

通过重参数化从学得的条件分布中采样。

(3)x^m=μθ(xu)+σθ(xu)⊙y,y∼N(0,1).

where ⊙ denotes elemen-wise multiplication, x^m denotes the conditionally mapped tokens, and y is a standard normal vector of the same dimensionality as xm.

其中，⊙ 表示逐元素乘法，x^m 表示经条件映射得到的词元，y 是与 xm 同维的标准正态向量。

Structurally, as shown in Fig.4, we first initialize the masked tokens from a standard normal distribution to serve as the objects for conditional mapping, denoted as y.

在结构上，如图 4 所示，我们先从标准正态分布采样以初始化被掩码词元，并用 y 表示这些待进行条件映射的词元。

The unmasked tokens are first passed through a normalization layer and then fed into a self-attention layer, allowing token information to propagate across the sequence.

未掩码词元先经过归一化层，再输入自注意力层，使词元信息能够在整个序列中传播。

Next, an MLP predicts the conditional mean and variance, and the masked tokens initialized from the standard Gaussian are mapped, using the predicted conditional mean and variance, to the target tokens in the sequence.

接着，MLP 预测条件均值和方差，利用这两个预测量，将以标准高斯分布初始化的被掩码词元映射为序列中的目标词元。

Finally, the unmasked tokens xu are concatenated with the conditionally mapped tokens x^m to form the reconstructed token sequence.

最后，将未掩码词元 xu 与经条件映射得到的词元 x^m 拼接，得到恢复后的词元序列。

The TFP module models masked tokens xm conditioned on unmasked tokens xu as samples from a conditional Gaussian distribution.

3.3. Token Semantic Guided Understanding

3.3. 词元语义引导的理解

Unlike conventional paradigms [15, 28, 33, 34, 39] that reconstruct images before feeding them into LVLMs, our TFGC framework directly enables LVLMs to perform understanding tasks on reconstructed token sequences.

传统方法 [15, 28, 33, 34, 39] 先重建图像，再输入 LVLM。TFGC 则让 LVLM 直接在恢复后的词元序列上执行理解任务。

From the token flow perturbation analysis, 1D tokens exhibit a holistic property, carrying fine-grained visual details and latent semantic potential.

词元流扰动分析表明，一维词元具有整体性，携带细粒度视觉细节和潜在的语义信息。

While these tokens implicitly contain semantic correlations, they remain visually oriented and lack explicit alignment with the linguistic space of LVLMs.

虽然这些词元隐含语义关联，但其表示仍偏向视觉，与 LVLM 的语言空间缺少显式对齐。

By explicitly guiding this latent semantics through the proposed Token Semantic Guidance (TSG) module, the reconstructed token sequence can be directly interpreted by LVLMs without decoding it back into an image.

通过所提出的词元语义引导（TSG）模块对潜在语义进行显式引导，LVLM 可以直接解释恢复后的词元序列，无需将其解码回图像。

This enables a more efficient, image-independent pathway for machine-oriented understanding.

这为面向机器的理解提供了更高效、无需重建图像的路径。

TSG Module.

TSG 模块。

For the image reconstruction path, these tokens primarily capture structural and visual information optimized for reconstruction rather than semantics.

在图像重建路径中，词元主要捕获服务于重建的结构与视觉信息，其优化重点在于重建。

The TSG module injects CLIP-driven semantic priors and projects these tokens into a language-compatible embedding space.

TSG 模块引入由 CLIP 提供的语义先验，并将这些词元投影至与语言模型兼容的嵌入空间。

Concretely, the reconstructed token sequence is first projected by an MLP into the LLM embedding dimension,

具体而言，先由 MLP 将恢复后的词元序列投影至 LLM 的嵌入维度，

then refined by stacked TSG layers—each composed of normalization, self-attention, and residual MLP blocks—to propagate and align semantic information.

再经多层 TSG 细化，通过各层的归一化、自注意力和残差 MLP 模块传播并对齐语义信息。

Finally, the semantically guided tokens are concatenated with textual prompts and fed into the frozen LLM to produce the final result.

最后，将经语义引导的词元与文本提示拼接，送入冻结的 LLM，得到最终结果。

This process transforms the information flow from a vision-centric reconstruction pathway to a language-oriented semantic reasoning stream, bridging the gap between visual compression and linguistic understanding.

这一过程将以视觉重建为目标的信息流转换为面向语言的语义推理信息流，弥合视觉压缩与语言理解之间的差距。

Progressive Semantic Alignment Training Paradigm.

渐进式语义对齐训练范式。

To bridge the modality gap between reconstruction-oriented visual tokens and the linguistic feature manifold, we propose a Progressive Semantic Alignment (PSA) paradigm for training the TSG module.

为弥合面向重建的视觉词元与语言特征流形之间的模态差距，我们提出渐进式语义对齐（PSA）范式来训练 TSG 模块。

This design ensures stable convergence and avoids the instability of directly optimizing a high-dimensional mapping without semantic priors.

这种设计有助于稳定收敛，避免在缺少语义先验时直接优化高维映射所带来的不稳定性。

Stage I — Semantic Grounding.

阶段 I——语义锚定。

The first stage establishes an initial semantic anchor between compressed token embeddings and the latent feature space that the LLM’s visual encoder is familiar with.

第一阶段在压缩词元嵌入与 LLM 视觉编码器所使用的潜在特征空间之间建立初始语义锚点。

As shown in Fig. 5, the original image is passed through the frozen LVLM’s vision encoder and adapter to obtain the reference semantic features FVE, which serve as supervision targets.

如图 5 所示，将原始图像输入冻结的 LVLM 视觉编码器和适配器，得到作为监督目标的参考语义特征 FVE。

The TSG output FTSG is then optimized to align with FVE via a mean squared error (MSE) loss LPSA1.

随后使用均方误差（MSE）损失 LPSA1，使 TSG 输出 FTSG 与 FVE 对齐。

This semantic grounding step effectively constrains the representation space and provides a warm-up prior that stabilizes training, ensuring the tokens lie on a semantically meaningful manifold.

这一语义锚定步骤对表示空间施加约束，并为训练初期提供先验以提高稳定性，使词元落在具有语义意义的流形上。

Stage II — Instruction Alignment.

阶段 II——指令对齐。

Once semantically grounded, the focus shifts from feature similarity to functional alignment with instruction-level reasoning.

建立语义锚点后，优化重点从特征相似性转向与指令层面推理的功能对齐。

Here, FTSG is concatenated with the text tokens and fed into the frozen LLM for next-token prediction, enabling the model to learn task-level instruction alignment.

将 FTSG 与文本词元拼接，送入冻结的 LLM 预测下一个词元，使模型学习任务层面的指令对齐。

This stage uses a joint loss LPSA2 combining cross-entropy and the semantic regularization term.

这一阶段采用联合损失 LPSA2，结合交叉熵和语义正则项。

Through this refinement, the TSG output evolves from static semantic resemblance to functional compatibility, enabling LVLMs to directly consume compressed token streams for downstream reasoning tasks.

经过进一步优化，TSG 输出从静态的语义相似发展为功能上的兼容，使 LVLM 能够直接使用压缩词元流完成下游推理任务。

Figure 5. Progressive Semantic Alignment (PSA) training paradigm.

图 5. 渐进式语义对齐（PSA）训练范式。

Stage I (Semantic Grounding): TSG output tokens are aligned with the frozen vision encoder’s features via MSE loss.

阶段 I（语义锚定）：通过 MSE 损失，将 TSG 的输出词元与冻结视觉编码器提取的特征对齐。

Stage II (Instruction Alignment): semantically grounded tokens are concatenated with text tokens and optimized via combined MSE and cross-entropy objectives for next-token prediction.

4.1. Implementation Details

4.1. 实现细节

TFGC decouples the optimization for human perception and machine understanding into two stages, thus avoiding performance compromise between the two objectives.

TFGC 将人类感知和机器理解的优化分为两个阶段，以避免两个目标之间的性能折损。

For human perception optimization, we employ the TiTok-sl256 [61] as our initial 1D tokenizer and detokenizer, freezing the codebook while training encoder, decoder, and TFP modules.

在优化人类感知时，我们用 TiTok-sl256 [61] 初始化一维词元化器和反词元化器，冻结码本并训练编码器、解码器和 TFP 模块。

The overall loss is LTFP=αL2+βLperceptual+γLadv with α=1.0, β=1.1, and γ=0.1.

总损失为 LTFP=αL2+βLperceptual+γLadv，其中 α=1.0、β=1.1、γ=0.1。

The model is trained on ImageNet-1K [10] with batch size 32 on V100 GPUs.

模型在 V100 GPU 上使用 ImageNet-1K [10] 训练，批大小为 32。

For machine understanding optimization, the TSG module is trained using the proposed PSA paradigm while keeping previous components frozen.

在优化机器理解时，采用所提出的 PSA 范式训练 TSG 模块，同时冻结前面训练的组件。

We build upon InternVL2-1B [9] and use its frozen vision encoder and adapter for MSE supervision.

我们以 InternVL2-1B [9] 为基础，使用其冻结的视觉编码器和适配器进行 MSE 监督。

The model is trained on 380k image–text pairs from COCO [37], RefCOCO/RefCOCOg [24, 43], and VQAv2/OKVQA [16, 45].

训练使用来自 COCO [37]、RefCOCO／RefCOCOg [24, 43] 和 VQAv2／OKVQA [16, 45] 的 38 万个图文对。

5. Conclusion

5. 结论

In this paper, we introduce TFGC, a token-based flexible compression framework that effectively unifies human- and machine-oriented perception objectives.

本文提出 TFGC，一种基于词元的灵活压缩框架，有效统一了面向人类和机器的感知目标。

By leveraging token flow propagation for variable bitrate and token semantic guidance for direct LVLMs consumption,

TFGC 通过词元流传播实现可变码率控制，并通过词元语义引导使 LVLM 能够直接使用压缩词元，

TFGC addresses the critical misalignment of conventional techniques in ultra-low-bitrate regimes, which struggle to preserve semantic consistency with flexible bitrate control.

从而解决传统技术在极低码率下难以兼顾语义一致性与灵活码率控制的问题。

Through a coarse-to-fine training strategy, TFGC enables LVLMs to process compressed token streams directly without image reconstruction, achieving state-of-the-art machine understanding while maintaining satisfactory perceptual quality.

采用从粗到细的训练策略后，LVLM 可以直接处理压缩词元流，无需重建图像，在保持良好感知质量的同时实现先进的机器理解性能。

Extensive experiments demonstrate that TFGC provides an efficient and unified solution for visual communication systems that serve both human and machine perception.

大量实验证明，TFGC 为同时服务于人类与机器感知的视觉通信系统提供了高效的统一方案。
